# Iconos clay de OdontoFlow

18 iconos SVG nativos (`svg/*.svg`, `viewBox 0 0 96 96`) y `sprite.svg` con `<symbol>`. Sin variables CSS = activo a color; el reposo monocromo se aplica con `--ic-*`. Grano con un `<filter>` compartido; `--ic-grain:none` lo apaga (se apaga solo a 20–24 px). Fuente: `odontoflow-planning/mockups/iconos-clay/generar.py`.
